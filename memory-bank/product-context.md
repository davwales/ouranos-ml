# Product Context

## Purpose

- Provide API endpoints for ML model inference
- Support both text generation and time series forecasting
- Enable easy integration of new models

## Key Features

- REST API interface
- Modular architecture
- Support for multiple model backends (HF, LM Studio)
- Standardized request/response schemas

## User Flows

1. Text generation via /generate endpoint
2. Chat completion via /chat endpoint
3. Time series forecasting via /forecast endpoint
